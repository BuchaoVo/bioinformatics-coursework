## 1. 总体分析框架

### 1.1 观察单位与输入边界

| 项目 | WDBC：主分析 | CTG：扩展分析 |
|---|---|---|
| 每行含义 | 一份乳腺细针穿刺样本的图像形态特征记录 | 一段胎心监护信号片段 |
| 阳性定义 | malignant=1，恶性 | pathologic=1，专家判读病理型 |
| 阴性定义 | 良性 | 正常与可疑合并 |
| 特征数 | 30 | 21 |
| 训练集 | 341条，阳性127条 | 1279片段，209录音，阳性108片段 |
| 固定验证集 | 114条，阳性43条 | 424片段，73录音，阳性34片段 |
| 锁定测试特征 | 114条，仅审计特征和标识 | 423片段、70录音，仅审计特征和标识 |
| 开发集 | train+validation，共455条 | train+validation，共1703片段、282录音 |
| 不入模的字段 | sample_id、结局标签 | sample_id、recording_id、结局标签 |
| 交叉验证 | 分层五折 | 按recording_id分层分组五折 |
| 训练与指标bootstrap | 按记录重抽样 | 按整段录音簇重抽样 |

分组标识用于保持相关片段不跨训练/验证边界，不能作为预测变量。CTG的录音并不一定代表唯一孕妇，因此录音分组能够处理已知的片段依赖，但不能证明患者水平完全独立。WDBC缺少可用患者分组与时间信息，其独立性边界亦需保留。

数据审计记录每个集合的样本数、阳性比例、缺失单元格及重复特征行。特征重复不自动等同重复患者，不凭特征相同就删除原始固定划分中的记录。锁定测试标签未读取，所有报告均不含测试性能或测试阳性率。

### 1.2 两种内部评价不能当作两次独立复现

第一种评价是在原train拟合、原validation上计算指标；第二种评价将二者合并为开发集，在共享五折划分中训练和预测。它们部分使用相同记录，因此是互补的内部分析，不能视作两个独立队列的重复验证。

固定超参数先写入`protocol.json`。深度、树数和boosting学习率曲线用于解释机制，不据曲线最优点重新训练并宣称获得无偏性能。测试特征只用于结构审计，测试标签不参与任何环节。若将来进行正式模型选择，应先限定主要指标和选择规则，再冻结完整流程，最后一次性评价测试标签。

### 1.3 固定模型及控制变量

| 显示名称 | 关键固定设定 | 本次作用 |
|---|---|---|
| Logistic regression | StandardScaler→LogisticRegression；C=1；max_iter=5000 | 可解释线性基线 |
| RBF-SVM | StandardScaler→SVC；C=1；gamma=scale；probability=False | 非线性边界基线 |
| Tree (depth 4) | max_depth=4；Gini；未剪枝 | 延续原演示脚本的单树对照 |
| Tree (full depth) | max_depth=None；Gini；未剪枝 | 与深树bagging更直接对应的补充对照 |
| Bagging | 100棵不限深度树；按行bootstrap；全部候选特征 | 样本扰动后平均 |
| Random forest | 100棵不限深度树；按行bootstrap；每个分裂max_features=sqrt | 样本与节点候选特征双重随机化 |
| AdaBoost | 50个默认树桩；learning_rate=1 | 样本权重顺序更新 |
| Gradient boosting | 100轮；learning_rate=0.1；max_depth=3；log-loss | 负梯度顺序更新 |

全局模型种子为1010。LR/SVM的标准化在Pipeline内部，每折只用训练部分拟合均值和标准差。没有新增缺失值填补、类别加权或阈值搜索。两个单树对照需使用完整名称，不把“深度4树”与“不限深度树”的结果混写。

SVM的decision_function是分类分数，可用于ROC-AUC和AP；它没有概率语义。本次不对SVM计算Brier、log-loss或概率SD，也不进行可能破坏CTG分组边界的内部概率校准。分类指标使用各估计器的`predict`：SVM按决策分数0分界，概率模型通常按0.5分界，精确等于边界时遵从估计器自身的并列规则。

### 1.4 指标含义

ROC-AUC描述阳性与阴性的排序区分能力；AP采用`average_precision_score`，是按召回率增量加权的精确率汇总，本报告不将其与梯形积分的PR-AUC混称。Balanced accuracy为敏感度与特异度的平均，避免大多数类准确率掩盖少数类表现。Log-loss与Brier用于概率质量评价，分值越低越好；前者对高置信度错分惩罚更强。

CTG阳性比例较低，AP和balanced accuracy应与AUC共同阅读。PR曲线的无信息基线等于当前评价集合的阳性比例；不同阳性率数据集的AP不能直接当作模型跨任务优劣的依据。

## 2. A：单树为何不稳定

**科学问题。** 更深的树是否同时改善训练与验证表现？改变训练样本会不会改变第一条规则？

**实验A1：深度对照。** 固定数据、特征、随机种子和其余树参数，只改变`max_depth=1,2,3,4,None`。每个设定拟合一次，分别计算train与validation的ROC-AUC、AP、balanced accuracy、log-loss及叶节点数。结果保存在`tree-depth.csv`。

**实验A2：根节点扰动。** 从30份共同训练bootstrap中的前10份，各拟合深度2树，记录根节点特征和切分阈值。WDBC每份抽341次记录；CTG每份抽209次录音，带回被抽录音的全部片段。模型种子保持1010，以避免把模型内部随机种子变化与外部训练扰动混在一起。结果保存在`bootstrap-roots.csv`，原始深度2树的可读规则保存在`depth2-tree.txt`。

**如何绘图。** 图2a横轴为最大深度，最后一格标Full，纵轴为AUC；训练/验证使用不同线型，点表示实际运行结果，不平滑、不补造重复。图2b以根特征为纵轴、10次中出现次数为横轴，旁边写同一特征下阈值范围。不同特征具有不同单位，因此不把所有阈值合并计算一个SD。

**如何读图。** 训练表现改善但验证改善停滞或下降，是复杂度风险的证据；一次深度曲线不能给出普适最优深度。根节点改变说明切分规则对经验训练样本敏感。相关变量间替换可以同时造成规则变化与预测近似稳定，因此仍需G部分的预测波动实验。

**误差条。** A1各设定仅一次固定拟合，不绘虚构的置信区间。A2是10次结构频数，阈值范围表示观察到的最小值—最大值，不是95%CI。

## 3. B：投票和相关性怎样影响集成

**科学问题。** 丢弃概率信息后，多数类别是否总与平均概率一致？增加模型数量能消除多少方差？

先手算工作单四样本的多数票与三模型平均概率，以0.5作为演示阈值。该表是教学给定数值，独立于真实数据训练；B样本平均阳性概率为0.483333，软投票纠正了硬多数票的错误。不要把四行示例当作算法性能实验。

方差机制采用等方差、等两两相关的简化模型：

\[
\operatorname{Var}(\bar f_B)/\sigma^2=\rho+(1-\rho)/B.
\]

**如何绘图。** 图4d横轴为模型数B，采用对数刻度；纵轴为归一化平均预测方差。画ρ=0、0.1、0.5、0.9四条理论曲线，图题明确标注“theoretical illustration”。这是公式计算，没有样本误差条。

**如何读图。** 增加B可降低独立波动项，但平台由共同相关部分决定。理论ρ定义为训练扰动下同一对象的模型预测相关性；D部分在验证样本上计算的树错误相关是经验代理，两者不能无条件等同。平均不自动消除共同偏差，且平方损失的偏差—方差直觉不能机械转成0–1分类误差定理。

## 4. C：Bootstrap到底抽到了多少不同样本

**科学问题。** 抽n次为什么不等于保留n个不同样本？63.2%和36.8%在小样本下是否精确成立？

**实验。** 对n=5与实际train记录数各模拟1000次，每次有放回抽n次，记录独特样本比例U/n与袋外比例1−U/n。模拟种子为1010+n。这一小实验是“按记录抽样”的数学演示；CTG结果中n=1279的模拟不等于CTG模型稳定性使用的整录音簇抽样，二者不可混淆。

理论期望为

\[
E(U/n)=1-(1-1/n)^n,\quad E(O/n)=(1-1/n)^n.
\]

n=5时分别为0.67232、0.32768；n=341时分别约0.632661、0.367339。63.2%/36.8%是大样本近似，不应直接用于五个元素的手算。

**如何绘图。** 图2c展示n=5离散覆盖比例的直方图，图2d展示n=341的覆盖分布；横轴为独特比例，纵轴为1000次抽样的计数。实线标经验均值，虚线标理论期望。OOB比例等于1−独特比例，保存于CSV，可由同一坐标变换读取，无需重复画一幅形状镜像的图。

**如何读图。** 分布宽度来自抽样随机性；均值接近理论值体现实现正确，不表示每次都恰好63.2%。模拟误差会随重复数增加而缩小，但有限n的理论期望不会变成大样本极限。

**OOB估计。** 对每条训练记录，只平均未抽中它的那些树的预测，再统一计算指标。树数曲线在50、100、300树时保存OOB accuracy，1、10树不报告，以避免部分样本OOB树过少。这里的OOB accuracy是普通准确率，不是balanced accuracy，不得直接混作同一指标。

对CTG，标准Bagging/RF的内部bootstrap仍按行进行；一个片段袋外时，同录音其他片段可能在袋内，所以该OOB分数不足以估计新录音泛化。报告只将其列为机制演示，以分组CV为主要内部评价。

## 5. D：Bagging与随机森林的增益来自哪里

**科学问题。** 对同一数据，平均多棵深树是否改善表现和训练扰动稳定性？随机候选特征是否进一步降低错误相关性？

**实验D1：三模型主比较。** 使用深度4单树、100棵Bagging和100棵RF的固定validation指标，并结合G的共同bootstrap预测波动。另列不限深度单树作为控制基学习器复杂度的补充，避免将“聚合效果”与“树深度改变”混为一个原因。

**实验D2：树数敏感性。** 对Bagging与RF分别拟合B=1、10、50、100、300，其他设定和随机种子相同。它们以一致随机序列构造，便于比较前缀数量变化，但曲线仍只有一个种子，不代表所有随机化实现的平均表现。

**实验D3：树错误相关。** 从100树模型中取各树的固定验证类别，构造错误指示\(e_{bi}=I[\hat y_{bi}\ne y_i]\)。排除在全部验证样本上错误指示恒定的树，对其余树两两计算Pearson相关，记录分布、均值及参与树数。恒定变量相关无定义，不能把它们强填为0。另保存树概率残差相关作为辅助量。

**如何绘图。** 图4a/b分别画树数—validation AUC与balanced accuracy，树数用对数横轴并明确标1、10、50、100、300；图4c以两两错误相关为横轴画分布，虚线标均值。图4d的理论曲线与经验相关分开成图，避免让读者认为公式已经严格拟合了观测数据。

**如何读图。** 应同时看聚合指标、单树质量和相关性；更低相关性并不保证更高预测性能。后期曲线平台表示当前设定下平均趋稳，而非证明“所有数据50树就足够”。树对共享同一批验证样本，相关系数对也相互依赖，所以图4c不是数千个独立重复实验，不给它们套简单独立样本显著性检验。

**误差条。** 树数曲线没有重复种子，故无经验CI。错误相关分布描述树对异质性，不能解释为泛化AUC的误差范围。

## 6. E：Boosting如何顺序修正

### 6.1 学习率×轮数实验

**科学问题。** 较小学习率是否需要更多轮？训练损失继续下降时验证损失是否仍下降？

分别固定学习率η=0.03、0.1、0.3，每个模型拟合300轮、树深度3、seed=1010。用staged_predict_proba逐轮保存train与validation的log-loss、ROC-AUC和AP。此实验改变的是学习率及阶段数，数据、树结构上限和所有预处理保持相同。

图6采用2行×3列：每列一种学习率；上行为log-loss，下行为AUC；虚线表示train、实线表示validation。标注每条验证损失曲线的最小观察值与阶段，标注只是说明探索结果，不把该点称为通过独立评价选定的最佳模型。每个设定仅一个种子，不给训练/验证曲线画假置信带。

负梯度y−p定义在logit加法模型的损失梯度上。新树近似拟合这个方向，再更新F，而不是直接把y−p无约束加到概率上。训练损失下降与概率排序改进不是同义；log-loss和AUC可能不同步，这正是双行图的用途。

### 6.2 AdaBoost真实权重轨迹

补充脚本`trace_adaboost.py`在WDBC train拟合与主分析一致的50树桩AdaBoost，重构前10轮SAMME权重，逐轮验证重构加权错误率与模型保存的estimator_errors_一致。

二分类SAMME采用

\[
\alpha_t=\log[(1-\epsilon_t)/\epsilon_t],\quad
w_{i,t+1}\propto w_{it}\exp\{\alpha_tI[\text{错分}]\}.
\]

该规范与经典±1标签公式中\(\tfrac12\log[(1-\epsilon)/\epsilon]\)的系数相差2，但归一化后的相对样本权重更新一致，不应混用公式系数。

轨迹样本按原始train顺序选首轮错分前4条和首轮正确前4条，不按后续权重最大值择优挑选。逐轮保存权重前后值、是否错分、相对更新倍率。可以绘制样本权重折线与当前错分样本总权重变化；它们解释训练注意力重新分配，不能理解为患病概率、样本重要性因果效应或外部性能。

### 6.3 实现家族比较

XGBoost、LightGBM和sklearn梯度提升均属于梯度提升树家族，本次只比较原理，不安装运行前两者。XGBoost强化目标近似、正则化、列抽样和稀疏工程实现；LightGBM强调直方图、叶优先生长及可配置的GOSS/EFB等。sklearn的HistGradientBoosting也提供直方图及缺失处理能力，不能把“二阶信息、直方图、可处理缺失”一概称为其他库独有。

## 7. F：公平比较与条件性选型

**科学问题。** 集成是否优于简单基线，增益在共享CV折中是否一致，解释成本是否值得？

开发集采用一次共享五折：WDBC为StratifiedKFold(n_splits=5,shuffle=True,random_state=1010)；CTG为同参数的StratifiedGroupKFold，并传入recording_id。每个模型使用完全相同的折。报告每折指标、五折均值和样本SD（ddof=1）；保存折外预测以供审计。

**如何绘图。** 图3a–c分别展示WDBC的五折AUC、AP和balanced accuracy。每个小点是一折；大点为五折均值；横线为均值±1个折间SD。图3d/e展示固定validation的ROC/PR曲线，使用原始连续score，SVM分数不做伪概率转换。CTG的分组CV放在图8a–c，采用一致模型色和相同指标定义。

**如何读图。** 五折SD描述折间异质性和当前划分敏感程度，不是均值的标准误，更不是95%CI。CV训练集相互重叠，不能把5折作为5个完全独立研究。模型间差距小于SD可以提示证据有限，但“大于SD”本身也不等于统计显著。开发集与固定validation排名不一致，应记录这种不稳定性，不按想要的结论挑选结果。

结果表包括八个预设模型；主比较图保留课程的七个主要模型，不限深度树作为稳定性和补充表对照。模型选择应综合表现、概率质量（适用时）、稳定性、解释成本和验证范围。不能因图上一条曲线略高就推断临床价值。

## 8. G：把训练稳定性与指标区间分开

### 8.1 共同训练bootstrap：模型是否对训练扰动敏感

采用30份共同外层bootstrap样本，rng=1010，各模型的内部种子固定1010。WDBC每次从341条train记录有放回抽341次；CTG每次从209个train录音有放回抽209次，所抽录音的全部片段随簇进入训练，录音被抽多次则对应片段重复多次。因簇长度不同，CTG每轮训练片段总数可变化。

重训模型为深度4单树、不限深度树、Bagging、RF、GB和LR。固定评价对象始终为原validation，既不重抽验证集，也不在这些重复中重新选择参数。

对每个验证样本i计算：

\[
s_i=\operatorname{SD}_{b=1}^{30}\{p_i^{(b)}\},\qquad
r_i=\frac1{30}\sum_{b=1}^{30}I[\hat y_i^{(b)}\ne\hat y_i^{(0)}].
\]

其中\(\hat y_i^{(0)}\)为用全部原train拟合的该模型类别。汇总\(s_i\)分布与均值，以及平均相对基准翻转率\(n^{-1}\sum_i r_i\)。另外报告“30次重训中两种类别都曾出现”的验证样本比例。这个“任意类别变化比例”不同于平均翻转率；也不同于“至少一次偏离全train基准”比例。

**如何绘图。** 图5a为每个验证样本的SD点图叠加箱线图；箱体表示样本SD的25%–75%分位数，箱内横线为中位数，须为1.5IQR范围，菱形为均值。点的纵向抖动只防遮挡，不改变SD。图5b分别用实心圆和空心方块表示两种类别变化指标。CTG的概率SD分析在图8d，两种类别变化指标另见结果CSV及答题附件。

**如何读图。** 每个点是一个验证样本的训练敏感度，不是一次训练的指标；箱体不是模型准确率CI。30次抽样越多，“至少出现两种类别”的样本比例通常越容易升高，所以应固定重复数比较。RF内部仍使用行bootstrap，但CTG外层训练扰动以整录音为单位，两层随机化承担不同角色。

### 8.2 固定模型的配对验证bootstrap：指标差值有多稳定

冻结原train拟合模型，随后仅重抽validation索引。WDBC每次从114条记录有放回抽114次；CTG每次从73个validation录音有放回抽73次并保留整簇。rng=3010，共请求2000次；若抽样后仅一类标签，AUC无定义，该次整体跳过，并记录有效与无效重复数。

对每一次抽样，同一索引用于RF、深度4单树、Bagging、LR、GB，分别计算AUC和AP，并在同一次抽样中做RF减去对照的差值。以差值经验分布的2.5%和97.5%分位数构建95%百分位区间。

**如何绘图。** 图5c/d分别画WDBC的ΔAUC和ΔAP；图8e展示CTG的ΔAP，CTG的ΔAUC另见结果表。点为原固定validation上的指标差，横线为配对bootstrap百分位区间，虚线0表示无差异。差值方向统一为RF−对照；正值表示RF在该指标上更高，不能随图反向。

**如何读图。** 区间仅反映固定模型在当前validation经验分布下的抽样波动，没有覆盖重新训练、超参数搜索、选模或新医院人群漂移。validation还参与机制探索，因此这些区间属于描述性内部证据，不能自动转成确认性显著性主张。CTG按录音抽样正确处理已知簇依赖，但不能等价于患者级或医院级外部验证。

## 9. 特征解释：模型依赖不等于因果作用

该分析对应D3，并服务于F/H的解释成本讨论。固定原train拟合的100树RF，计算MDI与validation置换重要性。置换评分使用ROC-AUC，每特征30次随机置换、seed=1010；保存每次AUC下降、均值和样本SD（ddof=1）。相关矩阵只使用train预测特征，保存Pearson与Spearman两种版本，主图使用Spearman。

图7a展示MDI前8特征与置换重要性前3特征的并集（9个变量）的Spearman相关矩阵，色标固定−1至1；图7b展示相同特征集合的MDI；图7c展示同一特征集合的置换AUC下降，误差条为30次置换的±1 SD。统一特征集合与次序可以直接看出两种指标的分配差异；全体特征排名保存在CSV，不能将图中所选9个变量误称为“置换重要性前9”。

MDI会受到可切分位置数量和相关替代变量影响。单独打乱某个变量后，其他相关变量可能仍保留同类信息，因此小置换下降不表示该生物学变量完全无关。置换得到负下降也不需删除：它可能来自验证样本随机波动或特征扰动改善某些排序。置换SD只是同一验证集上打乱方式的随机波动，不是独立样本上的因果效应CI。

CTG置换实现按片段行打乱，是描述性模型依赖分析；它可能改变录音内部结构或生成不自然组合，不作为独立组推断，也不反馈至模型筛选。

## 10. H：将证据组织成作业结论

必做Bagging/Boosting表应按六个方面比较：训练方式、每轮样本或权重、典型基学习器、主要偏差/方差作用、噪声及轮数敏感性、关键超参数。使用“主要降低”而不是绝对化的“只降低”，并注明RF属于Bagging式树集成的一种扩展。

250–400字备忘录应同时包含：当前数据下保留哪个模型及其表现依据；共同bootstrap是否支持稳定性改善；解释成本与特征重要性边界；本研究仅内部验证且测试标签未解锁；一条会改变当前选择的后续证据。后续证据宜具体，如独立录音或外部队列上AP/BA与校准的稳定改善，且收益达到预设实际意义，而不只说“以后收集更多数据”。
